# Face Assist

Object-oriented programming project developed in 2024 as an academic project to analyze facial expressions and age through a webcam.

The project simulates a banking self-service system, including user authentication and operations such as balance checking, statements, withdrawals, deposits, bill payments, and transfers. Facial analysis is used to identify emotions and calculate a probability of user uncertainty during interaction.

## Technologies

* Python
* DeepFace
* OpenCV
* Tkinter
* Object-Oriented Programming
